# JLPT Choukai & Dokkai Flashcards

Interactive flashcard website for studying Japanese vocabulary used in the **JLPT Choukai (聴解 / Listening)** and **Dokkai (読解 / Reading)** sections.

## Features

- **All JLPT levels**: N5 → N1
- Study modes:
  - Japanese → English (with reading)
  - English → Japanese
  - Reading (hiragana) → Meaning
- Flip cards with smooth 3D animation
- Progress tracking (known cards saved in browser localStorage)
- Shuffle, Previous / Next, Again / Know
- Keyboard shortcuts (`Space`/`Enter` flip, arrow keys navigate, `1` Again, `2` Know)
- Dark / Light theme
- Responsive design

## Live Demo

Open `index.html` in any modern browser, or enable GitHub Pages on this repository.
